# الكنترول المدرسي

تطبيق أندرويد (Flutter) لإدارة القيد ورصد الدرجات واستخراج النتائج. قاعدة البيانات محلية SQLite ولا يحتاج إنترنت.

## الهيكل
مبني على هيكل مشروع «المنصة الأكاديمية» نفسه: مجلد android، خط Cairo، وملف البناء `.github/workflows/build-apk.yml`.

## البناء
1. ارفع المجلد إلى مستودع GitHub.
2. شغّل Actions ثم Build Android APK (لا يحتاج أي secrets).
3. حمّل الملف من Artifacts.

## الإعدادات
من شاشة الإعدادات: سقوف الدرجات، نسبة النجاح، أقصى مواد للدور الثاني، حدود التقديرات. القيم الافتراضية مؤقتة وتطابق مع لوائح الوزارة.

## المرحلة 2
اللجان: توزيع تلقائي (سعة اللجنة وفصل الذكور عن الإناث من الإعدادات)، كشوف المناداة PDF، وبطاقات أرقام الجلوس.

## المرحلة 3
كشف النتائج مرتباً (ترتيب تنافسي) مع الطباعة PDF، وشاشة الإحصاءات لكل صف وطباعتها.

## الإصدار 2.0
واجهة جديدة بخمس تبويبات (الرئيسية، الطلاب، الدرجات، التقارير، الإعدادات)، حضور وغياب، درجات فصلية وشهرية،
شهادات شهرية (3 في الصفحة) وإشعارات (4 في الصفحة) وشهادات نتيجة، مركز Excel (xlsx وcsv) للتصدير والاستيراد،
نسخ احتياطي واستعادة، وإدارة المواد.
